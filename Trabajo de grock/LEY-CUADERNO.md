# LEY CUADERNO (anti-alucinación)

En cada input de trabajo FROMTED / infra:

1. Leer `TAREAS-EN-CURSO.md` — solo lo que está en curso
2. Leer `BITACORA-RESUMEN.md` — referencias, no detalle
3. Leer docs activos del proyecto (`PROYECTO-FROMTED.md` + `PASO-N.md` en curso)

Reglas:
- Tareas: si una fase se cumplió → borrar de en curso y crear la siguiente
- Bitácora: solo referencia a lo en curso y hitos cerrados
- Memoria del modelo: solo proceso clave del momento + esta ley
- No memorizar todo el proyecto; el cuaderno es la fuente de verdad
- Secuencia FROMTED: Spec cerrada → PASO 1 investigación/sources → PASO 2 diseño visual → construcción

Imágenes de diseño: **después** de la investigación (PASO 2), no antes.
