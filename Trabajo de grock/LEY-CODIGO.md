# LEY-CODIGO (única regla operativa de código)

Actualizado: 2026-07-28 19:17 -05

## Prohibido
- Escribir código desde 0.
- Programar UI sin source materializado en `fromted/sources/` (archivos reales).
- Tratar CSS como código fuente.
- Guardar en memoria MD más reglas de código aparte de esta ley.

## Obligatorio cada salida
1. **SOURCE:** indicar código Open Source usado, path en repo fromted/GitHub, trazabilidad (commit/inventory) y qué uso se le dio.
2. **Acción:** solo adaptar / fusionar / conectar / mejorar. Si no hay source materializado → no escribo código; solo descarga determinista.
3. **Tokens (Cursor):** en ≤5 líneas: qué revisaste de la tarea, cómo elegiste el camino más corto, plan de la tarea antes de ejecutar.

## Cada 5 salidas
Guardar en BITACORA-RESUMEN historial de pasos de esas 5 salidas.

## Antes de código
Releer: TAREAS-EN-CURSO.md + BITACORA-RESUMEN.md + inventory.json + LEY-CODIGO.md
