# Sistema de subida de documentos — frontend

## Cómo subir
1. Repo GitHub `frontend`.
2. Carpeta `reception/`.
3. **Add file → Upload files**.
4. Sube docs de UI/diseño/specs (`.md` `.yaml` `.json` `.txt`).
5. Commit a `main`.

## Cómo funciona
- Bandeja de entrada del frontend.
- Lectura literal por Wordflow/agente (FC-08).
- Sin handoff verificado → BLOCK programación.
