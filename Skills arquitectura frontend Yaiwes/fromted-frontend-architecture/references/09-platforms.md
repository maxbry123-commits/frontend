# Platforms

Primary runtime: **single-file or static HTML+JS** (open in browser).

| Platform | How |
|----------|-----|
| Web | static files |
| Linux | same HTML; optional Electron later |
| Windows | same |
| Android | WebView / PWA |
| iOS | WKWebView / PWA |

Do not require a cloud API for factory or chat **local** mode.
MiniMax frontend-dev motion recipes optional. Tokens stay FROMTED.
